Fairness, z-scores, and p-values

The z-score measures the heads-minus-tails difference in standard-deviation units. Values near zero are ordinary under a fair-coin model.

z = (H − T) / √N

The exact two-sided binomial p-value adds the probabilities of all fair-coin outcomes at least as imbalanced as the observed result. It is not the probability that the coin is fair. A small value means the result would be unusual under the fair-coin assumption.

Confidence and credible intervals

The 95% Wilson interval estimates plausible values for the long-run heads proportion using a frequentist procedure with good small-sample behavior. Over repeated experiments, 95% of intervals produced this way would contain the true proportion.

The optional Bayesian interval uses a uniform Beta(1,1) prior and the posterior:

p | data ~ Beta(H + 1, T + 1)

Under that model, the displayed credible interval contains 95% of the posterior probability for the heads proportion.

Streak probabilities

For a fair coin, the probability that a specified ending sequence is either all heads or all tails for length k is:

P(matching run of length k) = 2^(1 − k)

The average wait from a fresh start until either side reaches k consecutive results is:

E[Tₖ] = 2ᵏ − 1

“Chance by now” is different: it considers every possible starting point and overlap in all N tosses, using an exact recurrence rather than multiplying independent chances.

Law of large numbers

As independent fair tosses accumulate, the heads proportion tends to move closer to 50%. This does not mean the counts must become equal, or that convergence is smooth. The absolute heads-minus-tails gap can grow while its percentage of the total shrinks.

Small samples naturally vary widely. More tosses narrow the range of proportions compatible with a fair coin, which is why the Wilson interval contracts as N grows.

Gambler’s fallacy

A streak does not make the opposite result “due.” If tosses are independent and fair, the next toss remains 50% heads and 50% tails regardless of the preceding sequence.

P(next is heads | any past sequence) = 1/2

Long runs become likely somewhere in a long history, but observing one does not create a balancing force on the next toss.

Run-length distribution

A “run” is a maximal block of identical results. Run lengths in a fair coin follow a geometric distribution with p = ½.
